# E-Commerce Project Description

## Overview

A full-stack e-commerce web application providing a seamless shopping experience. It allows users to browse products, filter by categories, manage their shopping cart, and place orders securely. The system includes an admin role for managing products, categories, and viewing orders.

## Core Features

- **User Authentication & Authorization:** JWT-based authentication with Role-Based Access Control (Admin vs. Customer).
- **Product Catalog:** Browse products, view details, and filter by categories.
- **Shopping Cart:** Add/remove items, adjust quantities, and calculate total prices dynamically.
- **Order Management:** Checkout process, order history for users, and order status tracking.
- **Admin Dashboard:** CRUD operations for Products, Categories, and viewing system-wide Orders.
- **Wishlist Management:** Allow users to save favorite products for future purchases, seamlessly moving items between the wishlist and shopping cart.
- **Advanced Admin Dashboard:** A comprehensive control panel for administrators to manage the entire e-commerce ecosystem. Features include:
  - Statistical overview (Total sales, active users, pending orders).
  - Data tables for managing users, products, and categories.
  - Order fulfillment tracking and status updates.

## Target Audience

- **Customers:** Browsing and purchasing products.
- **Admins:** Managing store inventory and tracking sales.
